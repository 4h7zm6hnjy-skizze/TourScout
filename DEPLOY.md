# Update auf GitHub Pages

1. ZIP auf dem iPhone/Computer entpacken.
2. Im GitHub-Repository `TourScout` die Dateien aus diesem Ordner hochladen und vorhandene Dateien mit gleichem Namen ersetzen.
3. `index.html` muss direkt im Hauptverzeichnis des Repositories liegen.
4. GitHub Pages bleibt auf `main` / `/(root)` eingestellt.
5. Nach dem Commit 1–5 Minuten warten.
6. Auf dem iPhone die Seite einmal neu laden. Falls noch die alte Version erscheint, Safari neu laden oder die zum Home-Bildschirm installierte PWA vollständig schließen und erneut öffnen. Der Service Worker verwendet einen neuen Cache-Namen.
