# TourScout – Hinweise zu freien Komponenten

TourScout selbst enthält in diesem Prototyp keine kostenpflichtige API und benötigt keinen API-Schlüssel.

Verwendete offene Komponenten/Daten:
- MapLibre GL JS – freie Open-Source-Software (BSD-3-Clause).
- OpenFreeMap – frei nutzbare Kartenbereitstellung ohne API-Key in der Standardkonfiguration dieses Prototyps.
- OpenStreetMap-Daten – Open Database License (ODbL); die vorgeschriebene Attribution wird auf der Karte angezeigt.
- BRouter – freie Open-Source-Routingsoftware (MIT).
- Overpass API – Zugriff auf OpenStreetMap-Daten über öffentliche Community-Instanzen.
- Nominatim – freie OpenStreetMap-Suche; öffentliche Instanzen haben Nutzungsregeln und Fair-Use-Grenzen.
- Browser Web Speech API – lokale/System-Sprachausgabe, keine kostenpflichtige Sprach-API.

Wichtig: "kostenfrei" bedeutet hier keine Lizenzgebühren/API-Abos. Freie Software und offene Daten haben trotzdem Lizenzbedingungen und Attributionen. Öffentliche Community-Server sind nicht als unbegrenzt garantierte Hosting-Infrastruktur zu verstehen und können Fair-Use-Limits haben.
